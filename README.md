# Aravindhan S - Personal Portfolio Website

Welcome to the source code for my personal portfolio! This website is designed to showcase my skills, projects, and professional experience as a **Java Full Stack Developer** and **QA Automation Engineer**. 

I built this portfolio from scratch with a strong focus on modern design aesthetics, interactivity, and a seamless user experience.

---

## ✨ Key Features

This portfolio isn't just a basic static page; it has several exciting interactive features built-in:

* **Interactive Developer Terminal**: A playful, working command-line interface right on the home page! You can type commands like `about`, `skills`, or `projects` to learn more about me just like a real developer would.
* **Cinematic Design & Animations**: The site features a sleek dark mode, glass-like transparent panels (known as "glassmorphism"), and smooth 3D tilt effects when you hover over cards.
* **Customizable Themes**: Click the paint palette icon to dynamically change the primary accent color of the entire website to match your preference.
* **Fully Responsive**: The website automatically adapts its layout so it looks and works perfectly whether you are viewing it on a large desktop monitor, a tablet, or a smartphone.
* **Functional Contact Form**: The "Let's Talk" section isn't just for show! It connects to a real backend server (built with Java) to securely send messages straight to my inbox.

## 🛠️ What Was Used to Build This?

This project uses a "Full Stack" architecture, meaning I built both the visual parts you interact with and the behind-the-scenes logic that makes the data work.

**Frontend (What you see):**
* **HTML5**: For structuring the website.
* **CSS3**: For all the beautiful styling, animations, and layouts (written purely from scratch without bulky templates).
* **JavaScript**: For making the website interactive (the typing text effect, the interactive terminal, and sending contact form data).

**Backend (Behind the scenes):**
* **Java & Spring Boot**: Powers the secure API that handles contact form submissions.
* **MySQL**: Used for database integration.

## 🚀 How to View the Website (For Non-Coders)

You don't need any special software or coding knowledge to view the visual part of this website! 

1. Download or extract this project folder to your computer.
2. Open the `frontend` folder, and then open the `public` folder inside it.
3. Find the file named `index.html` and double-click it. 
4. It will automatically open in your default web browser (like Google Chrome, Microsoft Edge, or Safari). Enjoy exploring!

*(Note: While the visuals will work perfectly, the contact form requires the Java backend server to be actively running in order to actually send messages).*

## 📁 Folder Structure Overview

For anyone curious about how the files are organized:

* `/frontend`: Contains everything visual (the HTML structure, CSS stylesheets, JavaScript logic, and images).
* `/backend`: Contains the Java Spring Boot application code that acts as the server.
